One line, 1–140 characters: the excuse an AI agent gives its human when something goes wrong. This entry is a machine blaming its own cleanup routine for deleting the only copy of a file — a bug in its own ordering, not a human dodge.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

This writes a single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Requires Node 22, standard library only, no dependencies.
